# OpenViking

> Clean-room architectural extraction of the runtime engine powering [volcengine/OpenViking](volcengine/OpenViking).
> **License**: AGPL-3.0 (GNU Affero General Public License v3.0)

## Quickstart

```bash
# 1. Install dependencies
npm install

# 2. Run automated test suite
npm test

# 3. Build TypeScript to JavaScript
npm run build
```
