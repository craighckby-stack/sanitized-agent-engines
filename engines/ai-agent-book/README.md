> Clean-room architectural extraction of the runtime engine powering [bojieli/ai-agent-book](bojieli/ai-agent-book).

## Quickstart

```bash
# 1. Install dependencies
npm install

# 2. Run automated test suite
npm test

# 3. Build TypeScript to JavaScript
npm run build
```
