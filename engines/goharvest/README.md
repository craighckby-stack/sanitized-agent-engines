> Clean-room architectural extraction of the runtime engine powering [obsidiandynamics/goharvest](obsidiandynamics/goharvest).

## Quickstart

```bash
# 1. Install dependencies
npm install

# 2. Run automated test suite
npm test

# 3. Build TypeScript to JavaScript
npm run build
```
